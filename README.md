# TEX- Tricorder

Der selbstgebaute Synästhesie-Tricorder von Ensign Tex Tameron (Star Trek Adventures), als installierbare Web-App.

Biodaten werden zu Klang und Farbe: gesundes Gewebe klingt in C-Dur und leuchtet tiefblau, ein Gift kratzt in verstimmtem Gelb.

**Modi:** BIO (Befunde für den Spieltisch) · AKUSTIK (Mikrofon) · PULS (Kamera + Blitz) · BEWEGUNG (Beschleunigungssensor)

**Steuerung:** A = Scan · ◀▶ = Modus · ▲▼ = Befund · B = Ton · Katze antippen = Hilfe

Auf Android in Chrome öffnen → Menü ⋮ → „Zum Startbildschirm hinzufügen“.

Fan-Projekt, kein Medizinprodukt.
